DIGITAL NOTICE BOARD SYSTEM
CS2307 - Internet Programming Lab Mini Project

TECHNOLOGIES
HTML, CSS, JavaScript, PHP, MySQL, XAMPP

SETUP
1. Install XAMPP.
2. Copy the digital_notice_board folder to C:\xampp\htdocs\
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open http://localhost/phpmyadmin
5. Import database/digital_notice_board.sql
6. Open http://localhost/digital_notice_board/

ADMIN LOGIN
Username: admin
Password: admin123

MAIN PAGES
Home: http://localhost/digital_notice_board/
Notices: http://localhost/digital_notice_board/notices.php
Admin: http://localhost/digital_notice_board/login.php

FEATURES
- Admin login
- Add notice
- Edit notice
- Delete notice
- Search notices
- Department filter
- Urgency filter
- MySQL database
- Responsive UI
